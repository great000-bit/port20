# SEO / GEO / AEO playbook: Great Emman-Wori

Positioning: full-stack software developer, UI/UX designer and graphic designer in Port Harcourt, Nigeria.
The site stays on greatemmanwori.cv for now (a .cv domain is Cape Verde's country code, revisit in about a year).

## Which "EO" each part of the site serves
| EO | What serves it |
|---|---|
| SEO | titles, descriptions, canonicals, sitemap with images, static prerendered HTML per route |
| GEO / LLMO | static body copy in raw HTML, llms.txt, llms-full.txt, AI crawler rules in robots.txt |
| AEO | FAQPage schema + visible FAQ, question-style headings, short factual answers |
| AIO (AI Overviews) | clear entity facts, FAQ answers, OfferCatalog with prices |
| Entity SEO / E-E-A-T | Person + ProfilePage + Organization graph, sameAs profiles, hasOccupation |
| SXO | one H1 per page, fast static first paint, clear CTAs |
| Local SEO | Port Harcourt / Rivers State / Nigeria in schema, FAQ and copy, en-NG locale |
| Image SEO | descriptive alt text, image sitemap entries |

## Do after every merge
1. Google Search Console: submit https://www.greatemmanwori.cv/sitemap.xml, request indexing for /, /graphics, /uiux.
2. Bing Webmaster Tools: submit the same sitemap.
3. Test one page in Rich Results Test and the Schema Markup Validator.

## Authority work (outside the site, biggest remaining lever)
- Make every profile say the same line and link to the site: LinkedIn, GitHub, X, Instagram, Threads, Behance, Dribbble, Upwork, Fiverr, Medium.
- Get listed in Nigerian directories (Nigerian developer/designer lists, Port Harcourt business listings) and on client sites ("Website by Great Emman-Wori" footer link).
- Ask past clients for a short testimonial with a link, and publish them on the site.
- Guest posts or interviews on Nigerian tech and design blogs.

## Content plan (each one targets a question people ask)
1. How much does a website cost in Nigeria? (price ranges, what drives cost)
2. How much does logo design cost in Nigeria?
3. UI/UX designer vs web developer: who do you hire first?
4. How to choose a web designer in Port Harcourt
5. Case study deep dives: one article per project (problem, process, result, numbers)
6. WordPress vs custom React site for a Nigerian small business
7. Brand identity checklist for a new Nigerian business
Each article: one H1, a 40 to 60 word direct answer at the top, FAQ block, Article schema with author = Person.
