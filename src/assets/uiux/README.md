# UI/UX project mockups

Drop mockup images into a folder named after the project slug and they appear
on that project's page automatically, in filename order:

    src/assets/uiux/adsfirr-meta-ads-platform/01-overview.webp
    src/assets/uiux/adsfirr-meta-ads-platform/02-dashboard.webp
    ...

Slugs are listed in `src/data/uiux.json`. Use WebP or JPG, about 1600px wide.
Add story text in the same file under `story`: `[{ "title": "...", "body": "..." }]`.
